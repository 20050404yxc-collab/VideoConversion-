## 已发现并修正的问题

- 第 2 版长文件名会撑宽 Qt 内部列表行，关闭横向滚动仍不能正确省略；通过列表持有的标准绘制委托约束行宽，保留原有行高。最小布局与完整窗口测试复测通过，长名称截图已检查。

- 第一版 HDR 合成素材缺少色彩标记，测试对预期拒绝行为失败。改用 x264 色彩参数生成，并实际探测出 `smpte2084`、`bt2020` 后通过；不能把错误测试素材当作 HDR 产品验证。
- Qt 5.12 离屏后端缺少字体并在 QMessageBox 展示中崩溃；原生 Windows 后端测试通过。本次验收使用原生后端，没有把离屏成功作为前提。
- 最小窗口展开日志时设置挤压重叠。添加可滚动设置区、保证最低高度及提示行空间，补充实际可见性断言并通过。
- 临时清理失败若保留当前事务槽会使后续项也无法分配输出。现在记录残留路径并释放当前槽；外部文件占用回归测试通过，仍只删除本任务临时文件。

## 部署及剩余验收

第 2 版界面已构建到 `build/app/release/VideoConversion.exe`，当前截图已更新；本轮没有重新生成 dist 压缩发布包。现有包与 GIF 演示仍为第 1 版，README 已明确标注。第 2 版高 DPI 与跨机布局尚未验证。

测试包由 `scripts/package_release.ps1` 生成，携带工具、Qt 依赖与许可证说明。移除开发 Kit 与工具 PATH 后，使用包内依赖的 6 项窗口测试全部通过；独立主程序可启动。窗口关闭行为由原生 GUI 用例验证。没有独立干净目标机证据。

以下未获得完整验收证据：无 Qt 开发环境的独立目标机器、人工播放器音画同步与画质/体积比较、真实摄像/手机素材的广泛兼容性、系统 ACL 不可写目录、真正未知时长媒体的端到端转换、HR 要求的 GitHub 地址与正式短视频演示。已有的完整帧解码不能替代人工播放器验收；“未知时长”目前仅有解析与进度逻辑证据。
