# 依赖与许可证

本项目通过独立进程调用 FFmpeg，没有链接 FFmpeg 库。发布包中各第三方组件保持自身许可证；下列信息记录本次包的来源，不替代对应许可证全文。

简单说：程序、Qt 和 FFmpeg 是不同组件，随包保留它们各自的许可说明。

| 组件 | 本次版本/来源 | 许可说明 |
|---|---|---|
| Qt Widgets/Core/Gui | Qt 5.12.12，现有 `D:/Qt` MinGW x64 Kit | Qt 开源版许可证见随包 LGPL/GPL 文件；动态链接，未修改 Qt |
| MinGW 运行库 | MinGW 7.3.0 Kit，`windeployqt` 自动复制 | GCC Runtime Library Exception 与 libstdc++ 许可；详见 GCC 官方许可 |
| FFmpeg/ffprobe | Gyan FFmpeg 9.0.2 essentials build | GPL v3+，原包 LICENSE 与来源说明随包提供 |
| x264/AAC 等工具内部组件 | 所选 FFmpeg 静态工具构建 | 按 FFmpeg 构建及组件许可处理；详情参考构建提供者和 FFmpeg 法律页面 |

源码入口：[Qt 5.12.12 源码](https://download.qt.io/archive/qt/5.12/5.12.12/single/)、[GCC 源码与许可证](https://gcc.gnu.org/onlinedocs/libstdc++/manual/license.html)、[FFmpeg 法律与源码说明](https://ffmpeg.org/legal.html)、[Gyan 构建与源码信息](https://www.gyan.dev/ffmpeg/builds/)。发布时需保留实际构建对应的源码获取方式与许可全文。仓库尚未由作者指定自有代码开源许可证，不能擅自宣布为 MIT 或其他许可。
